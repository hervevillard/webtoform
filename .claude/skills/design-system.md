## Typography

- **Primary font:** Plus Jakarta Sans (Google Fonts) — weights 400, 500, 600, 700, 800
- **Fallback:** Segoe UI, system-ui
- **Monospace (API key input):** Courier New

Loaded via `@import` in `style.css`. If Google Fonts is unavailable (offline), fallback chain kicks in automatically.

## Design Principles

1. **Warm over cold** — every surface uses the warm ivory/parchment palette, never pure white
2. **Gold as primary action** — CTAs, active states, highlights all use the Kente gold gradient
3. **Forest for success** — green success states reference African forest life
4. **Midnight for structure** — header, heavy text, borders use the deep midnight
5. **Terracotta for warnings** — amber/terracotta for caution states (not harsh red)

## Component Patterns

### Cards
- 3px top-edge rainbow gradient bar (gold → terracotta → forest)
- `border-radius: 14px`
- Warm shadow: `0 4px 24px rgba(28,28,46,.08)`
- Hover: shadow deepens + lifts 0px (handled by CSS)

### Buttons
- **Primary (gold):** gradient `#C9A84C → #B8860B`, midnight text, gold glow shadow
- **Success (forest):** gradient `#2D5A3D → #3D7A52`, white text
- **Ghost:** transparent, earth border, gold on hover

### Step indicator
- Active step: gold gradient circle + glow ring `rgba(201,168,76,.25)`
- Done step: forest green circle
- Connector line: gold→terracotta gradient when active/done

## PDF Form Design

The generated PDF also follows the African theme:
- Header: `#1C1C2E` (midnight) background with gold text
- Field borders: `#C9A84C` (Kente gold)
- Field background: `#FFFDF7` (warm ivory)
- Page background: `#FDFAF3`
- "Generated by Herve" + "WebToForm · AI Insurance Tools" in header (top-right)

## Updating the theme

1. Change CSS custom properties in `:root` in `static/css/style.css`
2. Update colour constants at the top of `modules/form_generator.py`
3. Update this file with the new values
4. Update the Design System section in `CLAUDE.md`
